مدیر زیرساخت مجازی

Virtual Infrastructure Manager (VIM)

مدیریت منابع مجازی IT اغلب توسط ابزار‌های مدیریت زیرساخت مجازیسازی (VIM) پشتیبانی می‌شود که به طور مجتمع منابع مجازی IT را مدیریت می‌کند و به یک ماژول مدیریت متمرکز وابسته است، در غیر این صورت به عنوان یک کنترلکننده شناخته می‌شود که بر روی یک کامپیوتر اختصاصی اجرا می‌شود. VIM ها معمولا توسط سیستم مدیریت منابع دربرگرفته می‌شوند.

VIM هماهنگی سخت‌افزار سرور را انجام می‌دهد تا نمونه‌های سرور مجازی را از مناسب ترین سرور فیزیکی زیرین ایجاد کند. که می‌تواند برای مدیریت طیف وسیعی از منابع IT در میان سرور‌های فیزیکی مختلف استفاده شود و امکان ایجاد، ذخیره، پشتیبان گیری، پچ کردن و نظارت را برای مدیریت متمرکز منابع مجازی، فراهم می‌کند. به عنوان مثال، یک VIM می‌تواند چندین نمونه از یک hypervisor را در سرور‌های مختلف فیزیکی ایجاد و مدیریت کند و می‌تواند یک سرور مجازی را از یک سرور فیزیکی به سرور فیزیکی دیگر انتقال دهد. شکل ۳-۷۶ یک سیستم مدیریت منبع شامل یک پلت‌فرم VIM و یک مخزن تصویر ماشین مجازی را نشان می‌دهد. VIM ممکن است دارای مخزن اضافی، شامل مخزن اختصاصی برای ذخیره داده‌های عملیاتی باشد.
